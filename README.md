# 全球具身智能公司全地图

在线版：**https://idadu.github.io/embodied-ai-top50/**

覆盖全球 **81 家**具身智能公司的逐家档案，含三张产业地图、双轴标签筛选与 **320 轮**融资明细。

**数据基准：2026 年 9 月 3 日。** 产业变化快，超过一个月请当历史快照读。

## 内容

| 文件 | 说明 |
|---|---|
| `index.html` | 单文件网页，无外部依赖，直接双击可看。三张产业地图 + 筛选搜索栏 + 全公司列表 |
| `全球具身智能公司全地图.xlsx` | 四个工作表：① 全球 50 强总表 ② 融资明细（逐轮，320 行）③ 观察公司（31 家）④ 口径与标签说明 |

三张产业地图：

- **A 价值链泳道**：七条泳道从算力底座到整机，每家公司出现在它涉足的每一层，看谁在跨层
- **B 估值 × 商业化**：纵轴估值（对数），横轴按离现金流的距离排列，看谁被高估
- **C 资本网络**：49 家最活跃投资方 × 65 家被投公司，双向悬停查版图

## 口径

- **构成**：全球估值 top50 + 观察公司 31 家（含特斯拉 Optimus 单列），合计 81 家
- **汇率**：非美元估值统一按 2026-09-02 中国银行折算中间价换算，USD/CNY 6.7829、USD/HKD 7.8415、USD/KRW 1374.77
- **排序**：优先采用已成交估值；确无成交价时才退而采用第三方买方报价，并在「估值口径」里标明未成交。公司方自报的目标价与基石报价一律不用于排序
- **标签**：双轴体系，技术栈（做什么）× 收入来源（靠什么挣钱），后者带 A/B/C/D 证据级，A 为审计口径、D 为推断
- **不纳入**：Prometheus（Jeff Bezos 与 Vik Bajaj 联合创办）做的是面向实体产品设计制造全链路的 AI 工程软件，创始人已公开表示与机器人无关，不计入本表

公开报道、招股书、交易所公告与访谈，逐条在页面内标注口径与存疑点。出货数据严格区分订单、意向订单、产量与经审计销量。欢迎指正。
